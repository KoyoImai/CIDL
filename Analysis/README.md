# 分析用ディレクトリ
分析用のプログラムを格納してあるディレクトリです．

## プログラムの全体像
分析に使用するプログラムの全体像は以下の通りです．
```
SSOCL/
├── deepinversion_cifar.ipynb    : DeepInversionによるcifar100の画像生成 
├── deepinversion_imnet.ipynb    : DeepInversionによるImageNet100の画像生成
├── deepinversion+_cifar.ipynb   : DeepInversion+によるcifar100の画像生成
├── deepinversion+_imnet.ipynb   : DeepInversion+によるImageNet100の画像生成
├── imnet_label2ctegory.json     : imagenetのラベル(nxxxxx)とカテゴリ名の対応表
├── label_confirm.ipynb          : ラベル確認用ノートブック
└── plot_feature_cifar100.ipynb  : cifar100の特徴量可視化用ノートブック
```
